# Tensegrity-casuals-docs

Documentation for the Clemson Tensagrity challange team **Casuals**


## How to setup

1. Install [Obsidian-md](https://obsidian.md/) or any other editor program you prefer
	- obsidian is cross platform and is the preferred way to contribute to these docs
2. Clone the git repository: `git clone git@github.com:hasithperera/Tensegrity-casuals-docs.git`
3. Modify and commit your changes as needed
	- Be as descriptive as possible to make others understand the impact

## Basics

- Keep all binary files inside `res`
- Use basic Markdown and LaTeX syntax as needed
- Open the `source control view` for easy git actions
